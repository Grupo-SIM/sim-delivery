# Stack
- Runtime/package manager: Bun 1.3.12; task graph: Turbo.
- TypeScript monorepo; formatting/lint: Biome + ESLint.
- Frontend: React 19, Vite, TanStack Router + Query, Base Web, Tailwind utilities, Zustand, i18next, Kubb-generated SDK, optional Tauri.
- Backend: Bun, Elysia, TypeBox, Better Auth.
- Tests: Bun test; frontend and backend expose `test:unit`.
