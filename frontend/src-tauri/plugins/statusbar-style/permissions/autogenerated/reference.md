## Default Permission

Default permissions for the statusbar-style plugin

#### This default permission set includes the following:

- `allow-set-appearance`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`statusbar-style:allow-set-appearance`

</td>
<td>

Enables the set_appearance command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`statusbar-style:deny-set-appearance`

</td>
<td>

Denies the set_appearance command without any pre-configured scope.

</td>
</tr>
</table>
